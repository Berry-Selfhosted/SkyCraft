# SKYCRAFT

**SKYCRAFT** — браузерный 3D-симулятор управления беспилотниками с элементами конструктора и сюжетной кампанией.

Проект разработан для хакатона. Игрок собирает собственный дрон, выполняет спасательные миссии и принимает решения, влияющие на дальнейшее прохождение.

## Возможности

- 3D-симулятор полёта с физикой управления.
- Конструктор дронов с выбором комплектующих.
- Магазин деталей, склад и система игровой валюты.
- 12 сюжетных миссий в открытой 3D-локации.
- Поиск и спасение пострадавших.
- Диалоги с ИИ-ассистентом АИДА.
- Влияние решений игрока на сложность миссий.
- Управление с клавиатуры и мобильных джойстиков.
- Локальное сохранение игрового прогресса.

## Запуск проекта

**Требования:** .NET 8 SDK.

```bash
git clone https://github.com/Berry-Selfhosted/SkyCraft.git
cd SkyCraft
dotnet restore
dotnet run --project Skycraft.csproj
```

Откройте адрес, указанный в консоли.

## Сборка

**Windows x64:**

```bash
dotnet publish Skycraft.csproj -c Release -r win-x64 --self-contained true -p:UseAppHost=true -p:PublishSingleFile=true -o ./publish
```

**Linux x64:**

```bash
dotnet publish Skycraft.csproj -c Release -r linux-x64 --self-contained true -p:UseAppHost=true -p:PublishSingleFile=true -o ./publish
```

Готовая сборка находится в папке `publish`.

## Цель проекта

Создать доступный браузерный симулятор БПЛА, объединяющий конструирование техники, управление полётом и сюжетные решения в условиях чрезвычайной ситуации.

**SKYCRAFT — Собирай беспилотники. Испытывай в полёте. Открывай новые возможности.**
